# Laboratorio 4 - Teoria de la Computacion

## Autores

- 23661 - Angel Merida

## Descripcion

Cuarto laboratorio del curso de Teoria de la Computacion. El repositorio incluye el codigo para el problema 1 del laboratorio: construccion del AFN resultante de aplicar el algoritmo de Thompson al arbol sintactico de una expresion regular, su dibujo y la simulacion del AFN para reconocer cadenas.



El programa lee expresiones.txt, procesa cada linea y guarda el arbol sintactico y el AFN de cada expresion como PNG en la carpeta salida.
